# References

This list records sources relevant to the focused ECAL/QML research plan. It is
not exhaustive, and it should be expanded as implementation work begins.

## AMS-02 Detector and ECAL

- AMS Collaboration, "The Alpha Magnetic Spectrometer (AMS) on the
  International Space Station: Part II - Results from the first seven years."
  Official collaboration site: <https://ams02.space/>
- AMS Collaboration, "The AMS-02 lead-scintillating fibres Electromagnetic
  Calorimeter." Use this as the primary ECAL detector-description reference
  when adding implementation details. Public metadata should be verified before
  citing a DOI in the final report.
- A. Kounine, Z. Weng, W. Xu, and C. Zhang, "Precision measurement of
  0.5 GeV-1 TeV electrons and positrons using the AMS Electromagnetic
  Calorimeter." arXiv: <https://arxiv.org/abs/1210.0316>.

## ECAL Proton Rejection and Machine Learning Context

- H. Hashmani, U. Akbas, and B. Demirkoz, "A Comparison of Deep Learning
  Models on the Proton Rejection Accuracy of the AMS Electromagnetic
  Calorimeter." arXiv: <https://arxiv.org/abs/2307.05463>.

## Particle Interactions and Detector Simulation

- Particle Data Group, "Passage of Particles Through Matter." PDG review:
  <https://pdg.lbl.gov/>.
- Geant4 Collaboration, "Geant4 User Documentation." Official documentation:
  <https://geant4-userdoc.web.cern.ch/>.
- Geant4 Collaboration, "Physics Reference Manual." Official documentation:
  <https://geant4-userdoc.web.cern.ch/UsersGuides/PhysicsReferenceManual/html/>.
